LIBMPV / FFMPEG (runtime\mpv-2.dll)
-----------------------------------
The file runtime\mpv-2.dll is an unmodified third-party Windows build of
libmpv that includes FFmpeg. It is a GPL build. ALMP does not change it.

Builds made by the GitHub Actions workflow download this pinned build and
check its SHA-256:
  zhongfly/mpv-winbuild, release 2026-10-23-1140d3cc29,
  file mpv-dev-x86_64-20261023-git-1140d3cc29.7z
  https://github.com/zhongfly/mpv-winbuild/releases/tag/2026-10-23-1140d3cc29
The URL and SHA-256 are also written in BUILD-INFO.txt inside the zip.

Where the source of this exact build comes from:
  - Build scripts and the list of libraries and versions it uses:
    https://github.com/zhongfly/mpv-winbuild
  - mpv source (the "git-1140d3cc29" part of the file name is the mpv commit):
    https://github.com/mpv-player/mpv
  - FFmpeg source: https://ffmpeg.org/download.html
ALMP does not host a copy of these sources at the moment.

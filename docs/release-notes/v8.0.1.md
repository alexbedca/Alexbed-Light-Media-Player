# ALMP v8.0.1

A safety and reliability update. **Everyone on v8.0.0 should update**, especially if you play
files from a USB stick, a memory card or a network drive.

## Fixed
- **Delete on USB sticks, memory cards and network drives.** These drives have no Recycle Bin, and
  v8.0.0 could delete a file there permanently without saying so. ALMP now checks the drive first:
  on your computer's own drives the file still goes to the Recycle Bin; on other drives you get a clear
  "this will be deleted permanently" question and nothing happens unless you click **Yes**. If the
  Recycle Bin cannot be used for any reason, the file is left alone.
- **ALMP no longer closes suddenly after an unexpected error.** It keeps running and writes a short
  report to `%LOCALAPPDATA%\ALMP\almp.log` on your PC (never sent anywhere). Pressing Left/Right before
  anything is playing can no longer cause trouble.
- **Opening several files from Explorer at once** now adds all of them to the same window, also while
  ALMP is still starting. Opening a file from Explorer **adds** it to the playlist and plays it; it no
  longer wipes the playlist you built.
- **Fullscreen:** the mouse pointer and the controls stay visible while a window such as the F1 help,
  a file picker or a message is open. The playlist drawer no longer closes while you type in its search box.
- **Closing ALMP while a big folder is still loading** no longer shows a crash.
- **Run at Startup** no longer freezes the window for a moment, and it now tells you honestly if Windows
  did not allow it (for example on school or office computers) instead of claiming success.
- **Sleep timer:** changing "When time is up" no longer restarts the countdown. The clock button's
  tooltip and the menu show the minutes left.
- **Old playlists:** `.m3u` files saved by Windows Media Player, Winamp and other older tools (with names
  such as "Café" or "Müller") now load fully. Saved `.m3u` files open correctly in other players.
- Album art saved as "Cover" or "Front" in MP3 files is now shown.
- If `mpv-2.dll` is missing or blocked, ALMP shows a clear message instead of not starting at all.

## Changed
- The **"Remember Playlist"** box is gone. It never worked: ALMP always starts clean. Old history files
  from v7 (`resume.json`, `last_playlist.json`) are removed from `%APPDATA%\ALMP` once, for your privacy.
- **Click anywhere on the progress bar** to jump there. The slider handles are a little bigger.
- **Enter** plays the selected playlist item. **Tab** moves between buttons, and the selected button now
  has a yellow outline.
- `Remove-ALMP-Defaults.bat` now also turns off Run at Startup and can delete ALMP's settings and log
  files if you want (it asks first).
- The zip now includes a `LICENSES` folder with the full licence texts of the software inside ALMP.

## Notes
- **ALMP is not code-signed.** The free SignPath Foundation code-signing application was declined for
  now because the project does not yet have enough public visibility. Windows SmartScreen may show
  "Windows protected your PC": click **More info**, then **Run anyway**. See [SIGNING.md](../../SIGNING.md).
- **Check your download:** in PowerShell, `Get-FileHash .\ALMP-v8.0.1-Portable.zip -Algorithm SHA256`.
  The result must match the value below exactly.
